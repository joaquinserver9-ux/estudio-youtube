Privacy Policy

Last updated: November 23, 2026

Estudio YouTube ("the app") is a desktop tool used only by its owner to manage their own YouTube channel through the YouTube API Services.

Data the app accesses

With the Google account holder's permission, the app uses these Google OAuth scopes:

  • youtube.upload: to upload videos the owner chooses and approves.
  • youtube.readonly: to read the channel name, video titles and public statistics (views, likes, comments).
  • yt-analytics.readonly: to read YouTube Analytics reports (watch time, average view duration, shares, subscribers gained).

How data is used and stored

  • Data is used only to upload the owner's videos and show the owner their own statistics.
  • The access token and statistics are stored only on the owner's own computer. There is no server, database or cloud storage operated by the app.
  • The app does not sell, share, transfer or disclose any data to third parties, and does not use it for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Instagram

The owner can also connect their own professional Instagram account through the Instagram API with Instagram Login. With the account holder's permission the app uses instagram_business_basic (profile name and media list), instagram_business_content_publish (to publish Reels the owner approves) and instagram_business_manage_insights (to read the owner's own media statistics). The same rules apply: data stays on the owner's computer and is never shared. Access can be removed in Instagram under Settings → Apps and websites.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's local data folder removes all stored tokens and statistics.
